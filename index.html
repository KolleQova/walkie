LAN Walkie-Talkie

Phone-to-phone voice over your local Wi-Fi. No server, no internet.

Microphone is blocked on this page. Browsers only allow the mic on https:// or localhost. Serve this file from HTTPS or from http://localhost (e.g. Termux: python -m http.server 8000, then open http://localhost:8000), or on Android Chrome set chrome://flags/#unsafely-treat-insecure-origin-as-secure to this page's address.

1 · Enable microphone

Both phones must be on the same Wi-Fi (or one phone's hotspot). Tap below and allow the mic.

2 · Connect the two phones

Once the host taps Connect, this screen switches to the walkie-talkie automatically.
